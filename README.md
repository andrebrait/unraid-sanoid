Sanoid for unRAID 

## Fork notice

This is a maintained fork of [Steini1984/unRAID6-Sainoid](https://github.com/Steini1984/unRAID6-Sainoid) by Steini1984. This fork carries on maintaining the plugin and publishes its own releases.

### Installation

In the Unraid web UI, go to **Plugins → Install Plugin** and enter:

```
https://raw.githubusercontent.com/andrebrait/unRAID6-Sainoid/master/unRAID6-Sanoid.plg
```

Installing over the original Sanoid plugin keeps your settings.

### Requirements

- Unraid 7.0 or later.
